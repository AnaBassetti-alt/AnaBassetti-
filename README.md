# BASSETTI. — Portfólio profissional

Website estático bilíngue de Ana Clara Bassetti. HTML5, CSS3 e JavaScript puro, sem dependências externas, fontes remotas ou etapas de compilação.

## Executar no VS Code
1. Extraia o ZIP e abra a pasta `bassetti` com File > Open Folder.
2. Abra `index.html` diretamente no navegador ou use a extensão Live Server (opcional): clique com o botão direito em `index.html` e selecione Open with Live Server.
3. Use PT / EN no cabeçalho para alternar o idioma. A escolha é guardada quando o navegador permite armazenamento local.

## Estrutura
- `index.html`: conteúdo semântico e versão padrão em português.
- `css/style.css`: identidade visual, layouts responsivos e acessibilidade.
- `js/script.js`: traduções, navegação, menu, animações e endereços.
- `assets/`: identidade e capas vetoriais locais.

## Personalização
Em `js/script.js`, preencha `contacts` com e-mail, GitHub e LinkedIn confirmados. Use URLs completas HTTPS para perfis. Preencha `projectLinks` com URLs reais, na ordem ELORA, Aplicações Financeiras, GENESIS e Ocarina Hub. Os links aparecem automaticamente; não existem botões de destino falso. Atualize o texto de tecnologias e endereços pendentes nas traduções `pending0` a `pending3` quando os dados forem confirmados. As capas SVG são artes conceituais originais, identificadas como tais; substitua por capturas reais quando disponíveis. Para adicionar um projeto, duplique um article na seção projects, inclua suas chaves de tradução e acrescente a URL à lista.

Os detalhes dos projetos abrem com o elemento HTML details, inclusive sem JavaScript. Não há alegação de experiência profissional além da visita técnica informada.
